# Fonts

Inter 4.001 by The Inter Project Authors (<https://github.com/rsms/inter>), licensed under the
SIL Open Font License 1.1 (see [OFL.txt](OFL.txt)). The static Regular, Bold and Italic TTFs come
from the npm package `@expo-google-fonts/inter@0.4.2` (the Google Fonts build).

Embedded (subset) into exported PDFs by `src/modules/pdf`. Covers Latin, Cyrillic and Greek;
CJK, Arabic and emoji glyphs are not included.
